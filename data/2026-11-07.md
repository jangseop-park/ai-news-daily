## 📄 Hugging Face Papers

- [DPDM: 에이전트를 위한 공유 조건부 예측기 기반 의사결정](https://huggingface.co/papers/2611.02075)
  에이전트 결정은 task 설명만으로는 알 수 없고 실제 배포 관측에서 드러나는 경험적 관계에 좌우됨. 여러 종류의 결정을 하나의 사전학습 learner가 푸는 조건부 예측 문제로 바꿈. 언어모델은 의미 표현만 제공하고 예측은 공유 predictor가 담당하는 구조임. upvote 113으로 1위임.
- [SLA: Continual Pre-training으로 Spatial-Language-Action 모델 확장](https://huggingface.co/papers/2611.08373)
  VLA 모델은 2D vision-language 사전학습 표현을 물려받아 3D 공간 이해가 약함. 공간 supervision을 task 적응 단계가 아니라 continual pre-training 단계에서 넣어 3D 공간 이해를 갖춘 로봇 조작 foundation 모델을 만듦.
- [TailSteer: 다회차 이미지 편집의 drift를 막는 trajectory-tail steering](https://huggingface.co/papers/2611.06741)
  편집 결과를 계속 재입력하면 작은 변화가 누적돼 심한 시각적 drift가 생김. 추가 학습 없이 diffusion 샘플링 trajectory 끝부분만 조정해 drift를 억제함. pretrained prior를 건드리지 않는 게 장점임.
- [EvoMemState: 개인 에이전트를 위한 진화형 메모리 상태](https://huggingface.co/papers/2611.03743)
  기존 LLM 에이전트 메모리는 사실을 독립 항목으로 저장해서 사실 간 관계와 시간에 따른 변화를 놓침. 사용자 메모리를 계속 갱신되는 상태로 관리해 장기 개인화 지원을 개선함.
- [PACT: Prefill-to-Autoregressive 모델 간 전이의 기회와 과제](https://huggingface.co/papers/2611.06976)
  큰 모델의 prompt 표현(prefill)과 작은 모델의 효율적 생성을 결합하는 latent communication 방식임. 성능과 추론 비용 사이 균형점으로 주목받지만, 기존 시스템은 따로 평가하기 어려움. 평가 프레임워크를 정리하고 기회와 한계를 분석함.
