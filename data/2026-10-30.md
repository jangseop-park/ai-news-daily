## 📄 Hugging Face Papers

- [실제 음향 환경을 위한 효율적 스트리밍 Audio-Visual Target Speaker Extraction](https://huggingface.co/papers/2610.32749)
  영상과 음성을 함께 써서 특정 화자 목소리만 실시간으로 뽑아내는 연구임. 원거리 소음·잔향·화자 1~15명을 담은 현실적 벤치마크 RealSSA를 공개함. 제안 모델 Falcon은 AV-TFGridNet 대비 파라미터 91.9%, 연산량 20.2배, GPU 지연 11.1배를 줄이면서 SOTA 품질을 냄. 오늘 upvote 149개로 1위임.
- [OmniShowcase: 다시점 이미지 기반 전방위 피사체 일관 영상 생성](https://huggingface.co/papers/2610.35684)
  참조 이미지 몇 장으로 360도 회전하는 피사체 영상을 만드는 연구임. 3D 에셋 기반 학습 데이터 자동 합성 파이프라인과 surface-normal 맵 조건화를 도입함. Showcase-4K 데이터셋과 ShowcaseBench를 공개했고 피사체 일관성·3D 일관성에서 SOTA임.
- [Sensorimotor Alignment: 로봇 정책 성공을 예측하는 플라톤적 지표](https://huggingface.co/papers/2610.31670)
  Platonic Representation Hypothesis를 로봇으로 확장한 연구임. 모델의 시각 표현이 물리적 움직임 구조와 얼마나 맞는지 재는 학습 불필요 지표 S²를 제안함. S²가 실제 로봇 작업 성공률과 상관관계를 보여 비싼 closed-loop 평가 전에 VLA·VLM 백본을 고르는 데 쓸 수 있음.
- [TAO: LLM 에이전트 서빙을 위한 도구 인지 공동 스케줄링](https://huggingface.co/papers/2610.37230)
  GPU 추론과 CPU 도구 호출이 번갈아 일어나는 에이전트 서빙용 스케줄러임. 도구 응답 준비 시점, 노드별 캐시 이득, 토큰량을 함께 고려해 동적 계획법으로 세션 배치를 정함. 기존 최고 대비 지연 최대 26.8%, TTFT 최대 36.3% 줄이고 디코딩 처리량은 최대 29.5% 늘림.
- [RealCLI: CLI 에이전트의 인간-에이전트 협업 통합 평가](https://huggingface.co/papers/2610.22507)
  CLI 에이전트가 작업 수행뿐 아니라 사용자와 얼마나 잘 협업하는지 함께 재는 벤치마크임. 정보를 조금씩 주고 지시를 바꾸는 가상 사용자 모드를 둠. 최고 성능 에이전트도 평균 49.2%, 협업 점수는 37.6%에 그쳐 조종 가능성·신뢰 보정·안전 경계 관리가 약점으로 드러남.
