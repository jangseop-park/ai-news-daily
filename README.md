- [Doc2Harness: 코딩 에이전트의 롱-호라이즌 하네스 엔지니어링 벤치마크](https://huggingface.co/papers/2610.20344)

- [방법은 많아졌는데 에이전트는 나아졌나? 에이전틱 강화학습 자기증류의 현실 점검](https://huggingface.co/papers/2610.19789)
