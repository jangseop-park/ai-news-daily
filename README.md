## 📄 Hugging Face Papers

- [OmniCompass: 옴니모달 영상 그라운딩·이해를 위한 종합 벤치마크](https://huggingface.co/papers/2610.18829)
  기존 영상 이해 벤치마크는 평가 차원을 일부만 다뤄 옴니모달 능력을 체계적으로 진단하지 못함. OmniCompass는 두 트랙으로 나뉘며, OmniCompass-VL은 시각 증거가 필요한 과제로 VLM을, OmniCompass-AV는 오디오·영상을 함께 봐야 하는 과제로 옴니모달 모델을 평가함. 각 트랙은 시간 그라운딩(TG), 공간 그라운딩(SG), QA 세 과제로 '언제 나오는지·어디 있는지·무슨 일이 일어나는지'를 측정함.
- [Waypoint-OPD: 게이팅된 온-폴리시 증류로 RL이 만든 정책 변화를 전이하기](https://huggingface.co/papers/2610.21601)
  정책 변화 증류는 교사의 RL 전후 로그확률 차이를 학생 궤적의 지도 신호로 재활용함. 그런데 이 끝점 변화만 보면 교사 학습 도중 행동 선호가 일관되게 변했는지 알 수 없고, 초기와 후기 변화가 서로 강화됐든 상쇄됐든 같은 끝점이 나올 수 있음. Waypoint-OPD는 같은 RL 런의 중간 체크포인트로 초기·후기 변화 방향이 일치하는지 비교해 끝점 변화를 게이팅함.
- [OpenGCUA: 범용 컴퓨터 유즈를 위한 완전 오픈 스택](https://huggingface.co/papers/2610.22200)
  컴퓨터 유즈가 GUI 조작만이 아니라 시각·프로그래밍 인터페이스를 함께 쓰는 쪽으로 넓어지는 전환점에 왔음. 모델이 어떻게 관찰·행동·작업 정리를 할지 스스로 고르는 시스템을 범용 컴퓨터 유즈 에이전트(GCUA)로 정의함. GPT-6 Astra 같은 프런티어 구현은 대부분 비공개라 설계 연구가 어려워, 전체 스택을 커뮤니티와 함께 공개하는 프로젝트임. 코드 실행이 핵심 설계로, 중간 결과가 다음 동작을 결정하게 함.
- [FDE-Gym: AI 전달의 마지막 1마일](https://huggingface.co/papers/2610.22350)
  기존 에이전트 벤치마크는 이슈 리포트나 티켓으로 잘 정의된 과제를 다루지만, 실제 고객 전달은 다름. 포워드 디플로이드 엔지니어(FDE)는 모호한 요구사항을 명확히 하고 살아있는 시스템에서 일하며 말로 안 된 제약을 찾아내야 함. FDE-Gym은 18개 업종 20개 고객 시나리오에서 뽑은 종단간 전달 과제 95개로 구성되며, 업계 전문가가 실제 프로젝트를 각색함. 고객 지표를 얼마나 개선했는지를 0~1로 정규화해 채점함.
- [RoTA-Bench: 상호작용형 투영 정렬로 3D 공간 추론 평가하기](https://huggingface.co/papers/2610.17665)
  비전-언어 모델이 2D 관측을 정확한 행동으로 이어지는 3D 이해로 바꿀 수 있는지 물음. 목표 실루엣을 주고 회전된 물체를 보여준 뒤, 제한된 행동 예산 안에서 회전을 연속 선택해 목표 투영을 복원하게 함. 2D 아이콘에서 실루엣 보존 3D 물체를 자동 생성하고 역방향 초기화로 풀 수 있음을 보장해 과제 674개와 100개 테스트셋을 만듦. GPT-5.6-Sol은 17%만 성공해 사람과 격차가 큼.
