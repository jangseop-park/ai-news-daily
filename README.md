## 📄 Hugging Face Papers

- [StreamEval: 인터랙티브 스트리밍 영상 생성 모델 평가 벤치마크](https://huggingface.co/papers/2610.28402)
  실시간 상호작용이 가능한 스트리밍 영상 생성을 평가하는 통합 벤치마크임. 아바타 대화·아바타 퍼포먼스·월드 생성·지시 편집·레퍼런스 편집 5개 태스크를 다루고, 15~300초 길이의 스크립트 테스트 케이스 300개로 구성됨. 태스크 수행·상태 일관성·시각 충실도·시청각 조화 4개 축에서 10개 지표로 0~100점 평가함. 모델 37종을 돌려보니 화질과 신원 유지가 좋아도 상태 변화 추적은 약하다는 점이 드러남.
- [SpatialScout: VLM 에이전트가 3D 장면을 능동적으로 탐색하고 지도화할 수 있는가?](https://huggingface.co/papers/2610.26659)
  VLM 에이전트의 객체 단위 능동 3D 매핑 능력을 평가하는 벤치마크임. 실내 장면 80개와 타깃 객체 3,140개로 구성되고, 에이전트는 객체 목록·RGB 관측·카메라 캘리브레이션·포즈를 받아 카메라를 직접 조작해 장면을 탐색하고 공유 좌표계에서 객체 중심 위치를 추정함. 제한된 상호작용 예산 안에서 시점 선택·뷰 간 연결·기하 추정·지도 수정을 동시에 조율해야 하는 과제임.
- [Cache Engineering for Agents — 에이전트를 위한 KV 캐시 엔지니어링](https://huggingface.co/papers/2610.28577)
  LLM 에이전트의 궤적이 길어지면 KV 캐시 I/O와 저장 비용이 지배적이 됨. 기존 컨텍스트 엔지니어링은 히스토리를 자르거나 요약해 캐시를 줄이지만, 궤적 앞부분을 수정하면 뒤쪽 캐시가 무효화돼 재프리필 비용이 크게 발생함. 이 논문은 궤적을 바꾸지 않고 에이전트가 활성 KV 캐시를 직접 제어하는 '캐시 엔지니어링'을 제안함. 재프리필 없이 캐시 증가를 능동적으로 관리할 수 있음.
- [DONIC: 사람 시연으로 배우는 범용 양손 정교 조작 추적 제어](https://huggingface.co/papers/2610.29997)
  기존 정교 조작 추적 모델이 대부분 한 손에 치우쳐 있어, 실생활에서 흔한 양손 동작을 다루지 못하는 문제를 겨냥함. 조작 카테고리와 사람 동작 소스를 함께 학습한 최초의 범용 양손 트래커 DONIC과, 객체 229종·시퀀스 1,575개로 접촉이 지속되는 양손 상호작용에 집중한 멀티뷰 데이터셋 BiHOI를 함께 공개함. PPO와 행동 복제를 피드백 루프로 결합함.
- [Looking Ahead: 자기회귀 영상 생성에서 미래 변화를 모델링하기](https://huggingface.co/papers/2610.29989)
  자기회귀 영상 확산 모델은 청크 단위로 영상을 만드는데, 그럴듯한 연속 프레임을 뽑는 것과 장면이 실제로 어떻게 변하는지 포착하는 것은 다른 문제임. 티처 포싱 학습에서는 시간적 중복성 때문에 국소적 시각 연속성이 손쉬운 지름길이 되어 변화 모델링 압력이 줄어듦. 중간 맥락 없이 시간적으로 떨어진 청크를 예측하는 보조 목표 FCP를 제안함. 추가 사전학습 인코더가 필요 없고 추론 방식도 그대로이며, 더 적은 학습 연산으로 물리적 타당성이 개선됨.
