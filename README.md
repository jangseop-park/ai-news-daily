## 📄 Hugging Face Papers

- [World Editing: 실행 가능한 월드를 깊이별로 개입해 편집하기](https://huggingface.co/papers/2610.02331)
  월드 모델이 환경을 생성하고 그 안에서 행동하는 건 되는데, 이미 있는 실행 가능한 월드를 의도대로 고치는 건 거의 안 다뤄졌음. 바뀌면 안 되는 속성은 유지하면서 개입하는 문제로 정의하고, 편집이 엔티티·동역학·시스템에 얼마나 강하게 얽히는지를 '개입 깊이'로 축을 세움. 상업 수준 게임 모딩으로 구현해 IGMWorld와 과제 110개·실행 가능 상태 1.1K개 이상의 IGMBench를 공개함.
- [의미 유사도를 넘어서: 복잡 과제용 에이전틱 검색의 성능과 비용](https://huggingface.co/papers/2610.05750)
  밀집 검색은 표면적 의미 유사도에 의존해서 복잡한 검색 과제에 부족함. LLM 추론과 리트리버를 ReAct 루프로 묶은 에이전틱 검색을 실험해 표준 검색보다 nDCG@10이 개선됨을 보임. 다만 비용이 함께 커지므로 성능-비용 트레이드오프를 정량화함.
- [COSMI: 다중 객체 상호작용의 조합적 합성](https://huggingface.co/papers/2610.03252)
  일상 활동은 여러 물체를 동시에 다루지만 데이터셋은 대부분 한 번에 하나만 기록함. 상호작용이 국소적이라는 관찰에서, 단일 객체 클립을 접촉 일관성을 지켜 조합하고 손 균형을 맞춰 미러링·신체 간 전이함. 언어모델과 기하 검사로 의미·물리적으로 그럴듯한 조합만 통과시킴.
- [비공개 건강기록을 증류해 에이전트로 혈액 바이오마커 발굴](https://huggingface.co/papers/2610.04749)
  일반 혈액검사(CBC)에서 새 바이오마커를 찾을 수 있지만 평가에 필요한 비공개 기록은 프런티어 모델에 넘길 수 없음. 환자 540만 명 이상 패널의 근거를 점수 도구로 증류해, 면역 매개 질환 13종별로 데이터 경계 안에서 그래프 어텐션 네트워크를 학습하고 가중치만 공개함. 에이전트의 제안-채점-수정 루프를 실제 데이터에 접지시킴.
- [LLM-as-Jev: LLM은 이미 Jev식 결정 모델임 — 언제·어떻게 파인튜닝할까](https://huggingface.co/papers/2610.02076)
  Jev식 결정 모델은 자유 텍스트 없이 미리 정한 옵션에 확률만 돌려줘서 소프트웨어가 바로 쓸 수 있음. 범용 LLM이 이 능력을 이미 어디까지 갖고 있고 파인튜닝이 언제 실제로 필요한지 조사함. 괄호 숫자 식별자에 대한 다음 토큰 확률에서 보정된 결정을 뽑는 구조 보존 프레임워크를 제시함.
