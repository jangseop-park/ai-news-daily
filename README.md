## 📄 Hugging Face Papers

- [WeVisOne-VL: 객체 단위에서 픽셀 단위까지 통합한 시각 인식 모델](https://huggingface.co/papers/2610.31329)
  기존 VLM이 세밀한 시각 인식에서 신뢰도가 낮은 문제를 겨냥함. 구조화된 next-token 예측으로 객체 단위와 픽셀 단위 인식을 하나로 묶은 모델임. 객체 검출·참조 위치 지정·카운팅·OCR·세그멘테이션·매팅을 모두 지원하고, 점·박스부터 마스크·알파 매트까지 사용자가 원하는 입도로 위치를 지정할 수 있음. <OBJ> 특수 토큰으로 경량 픽셀 디코더를 VLM에 붙이고, 3단계 커리큘럼 SFT 후 혼합 태스크 RL로 학습함. 30개 이상 벤치마크에서 선두 성능을 냈고, 객체가 없는 질의는 안정적으로 거부함. 오픈소스로 공개됨.
- [IQuest-Q1: 에이전트형 CLI 시스템을 위한 320B MoE 파운데이션 모델](https://huggingface.co/papers/2610.30949)
  총 320B 파라미터에 활성 15B인 희소 MoE 에이전트 파운데이션 모델임. 3단계로 개발됨. 먼저 Stable SplitNorm·Muon·muP를 결합한 안정적 사전학습에 2단계 커리큘럼을 써서 두 번째 단계에서 코딩 데이터 비중을 올리고, 안전 학습률과 최적 학습률 사이 안정 마진을 넓게 유지함. 다음으로 도메인·포맷을 넓히고 컨텍스트를 점진적으로 늘리는 중간 학습을 거침. 마지막으로 SFT와 도메인 특화 RL, MOPD를 여러 스캐폴드에 걸쳐 조합해 에이전트형 코딩 능력을 강화함. 단계별 전문가와 체크포인트를 병합할 때 파라미터 업데이트 충돌을 완화함.
- [Deep Search in Real-World Web Environments — 실제 웹 환경에서의 딥서치 평가](https://huggingface.co/papers/2610.30181)
  딥서치 에이전트가 많이 발전했지만, 실제 열린 웹에서 처음부터 끝까지 리서치를 수행하는 능력은 제대로 평가되지 않았다는 문제의식임. 정적 검색 설정과 달리 실제 웹 정보는 소스·모달리티·포맷이 제각각이고 복잡한 상호작용을 요구함. 라이브 웹에서 다단계 딥서치 능력을 재는 OpenDS 태스크를 제안함. 에이전트는 웹 검색과 브라우저 조작, 증거 처리를 거쳐 독립된 여러 출처의 근거를 스스로 찾아 연결하고 유일한 사실 답을 확정해야 함. 이를 바탕으로 OpenDS-World 벤치마크를 구축함.
- [LayerEditor: 이미지를 재사용 가능한 레이어로 편집하기](https://huggingface.co/papers/2610.24738)
  고품질 이미지 편집은 대상 영역만 정확히 바꾸고 나머지는 그대로 보존해야 함. 기존 편집 모델은 결과를 납작하게 합쳐 내보내서 국소 조작과 레이어 재사용이 어렵고, 분해 기법은 레이어 복원을 편집과 따로 최적화함. 지시 기반 편집과 재사용 가능한 RGBA 레이어 생성을 하나로 묶은 LayerEditor를 제안함. 편집된 캔버스와 순서가 있는 RGB-Alpha 레이어를 한 토큰 시퀀스로 함께 표현해, 의미적 편집과 개별 레이어 내용 제어를 동시에 가능하게 함. 사전학습 모델의 편집 능력을 유지하도록 Compositional Edit-Prior Distillation을 씀.
- [MLLM 잠재표현을 제대로 쓰기 — 영화적 영상 생성을 위한 요인 인식 예측 학습](https://huggingface.co/papers/2610.30926)
  영화적 영상 생성은 희소한 입력에서 시간적 추론을 하면서 캐릭터·장면·액션·카메라를 각각 제어해야 함. MLLM이 두 능력에 유용한 사전지식을 주지만, Video DiT가 자체 조건 경로로 이를 우회해버려 자동으로 활용되지 않는 문제가 있음. FAPL은 먼저 MLLM 잠재표현을 실제로 쓰게 만드는 것을 공통 전제로 세우고, 두 능력을 보완적 학습 신호로 각각 공략함. MLLM과 커넥터를 동결한 상태로 DiT를 학습시켜 잠재표현 활용을 강화하고, 요인별 제어는 짝지어진 영상으로 학습함.
